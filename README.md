# Eagles Nation Daily

Independent Philadelphia Eagles fan hub for [@eaglesnation.daily](https://www.instagram.com/eaglesnation.daily/).
Not affiliated with or endorsed by the Philadelphia Eagles or the NFL.

- `index.html` – the whole site (content data lives in the script at the bottom)
- `styles.css` – design system (midnight green / Kelly green themes)

Hosted on Netlify; every push to `main` redeploys the site.
